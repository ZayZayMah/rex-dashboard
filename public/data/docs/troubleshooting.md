## 1. Rex isn't responding
1. Open [Live stats](/live) to see whether Rex is online or in maintenance.
2. Check Rex can **View Channel** and **Send Messages** in that channel.
3. Make sure you are using a command available to you (type `/` and look for it).
4. Wait a moment and try again.

## 2. A command is missing or says you lack permission
- Check Rex is in the server and the command exists on the [Commands page](/commands).
- Check your Discord role permissions, or your staff role in *Roles and Permissions*.
- Check whether it needs a tier above the server's current one (see [Plans and Billing](/docs/plans)).

## 3. Rex can't perform an action
- Check the bot's channel and server permissions.
- Move Rex's role **above** the roles it manages.
- Read any error message from Discord.
- Run `/botperms` for a permissions check.

## 4. Dashboard problems
| Problem | What to try |
|---|---|
| Won't load | Check your connection, refresh, try another browser, try again later. |
| Login loops or fails | Clear this site's cookies and sign in again. Make sure you use the right Discord account and aren't blocking third-party sign-in. |
| My server isn't listed | You need *Manage Server* there and Rex must be in the server. Add Rex, then refresh. If needed, log out and back in. |
| A feature is missing | It may need a higher tier or a permission you don't have. |

## 5. Contact the Rex team
- **Website chat:** use the [Support page](/support) where it is available. Rex asks a few questions first and opens a ticket if a person is needed.
- **Support Server:** join the [Rex Support Server](support:) for help, bug reports and announcements.

### What to include
1. What you were trying to do.
2. The command or Dashboard page involved.
3. Any error message.
4. What you have already tried.

Please be respectful and patient. Never share your password, authentication codes or bot token.

## 6. Report a bug
Explain what happened and the exact steps that caused it, with any error text. Clear reports are fixed faster.

## 7. Security reports
Report suspected vulnerabilities privately as described in the [Security Policy](/docs/security).

## 8. Avoid scams
Only use official Rex links. Be cautious of anyone claiming to be staff and asking for private credentials. Real staff will not ask for them.
