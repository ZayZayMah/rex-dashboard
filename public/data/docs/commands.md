## 1. Using commands
1. Open a server where Rex is present and click a text channel.
2. Type `/` to open Discord's slash-command menu.
3. Choose a Rex command, fill in the options Discord shows and send it.

The complete, current list with usage and required permissions is on the [Commands page](/commands). It is the authoritative reference, because commands can change between updates.

## 2. Command areas
| Area | What it covers |
|---|---|
| Moderation | Bans, kicks, timeouts, warnings, AutoMod (Premium) and logs |
| Server management | Roles, channels, welcome and leave messages, verification, tickets |
| Community | Levels and XP, games, economy and fun commands |
| Custom commands and events | Build your own commands from blocks, no code needed (Premium and above) |
| Information | Server and bot information, status and permission checks such as `/botperms` |

Economy features use virtual currency only. It has no real-world value unless explicitly stated.

## 3. Settings
You can configure Rex in two places:
- **Dashboard** ([open it](/dashboard)): pick your server and use the side menu (Welcome and Leave, Levels and XP, Tickets, Verification, Logs, Protection and AutoMod, Roles and Permissions, Commands, Premium and more).
- **Discord**: use `/settings` and the other configuration commands.

The Dashboard shows more detail. Some options exist only in one place.

## 4. Why can't I use a command or setting?
Work through these in order:
1. **Permission:** your Discord role may not allow it. Moderation commands usually need the matching Discord permission or a staff role set under *Roles and Permissions*.
2. **Rex's permissions:** Rex needs View Channel and Send Messages in the channel, and its role must sit above roles it manages.
3. **Tier:** some features need Premium, Priority or Ultra. See [Plans and Billing](/docs/plans).
4. **Status:** check the [Live stats](/live) page for outages or maintenance.

## 5. Changing settings safely
- Read each option's description before changing it.
- Make sure you understand how it affects other members, especially access and moderation settings.
- Review the result after saving.
- Never grant extra permissions just to make something work without understanding the risk.

## 6. Custom commands and events
Open your server, then **Commands** in the side menu. Premium servers can create 5 custom commands and 5 events. Priority and Ultra servers can create unlimited ones.
