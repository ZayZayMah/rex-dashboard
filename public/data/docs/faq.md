## Frequently asked questions
### What is Rex?
Rex is a third-party, all-in-one Discord bot with tools for moderation, server management, levels, tickets, games and more, plus a web Dashboard.

### How do I add Rex?
Press **Add Rex** on the [home page](/) or in the [Dashboard](/dashboard). You need *Manage Server* in your server. See [Getting Started](/docs/getting-started).

### How do I use commands?
Type `/` in a channel where Rex can see and send messages and choose a Rex command. The full list is on the [Commands page](/commands).

### Why can't I use a command?
It may need a Discord permission, a staff role, a higher tier, or Rex may lack permission in that channel. See [Commands and Settings](/docs/commands).

### What tiers are there and what do they include?
Free, Premium, Priority and Ultra. See [Plans and Billing](/docs/plans) and the [Premium page](/premium).

### How do I get the free trial?
Join the [Support Server](support:) for the first time and your account gets a 7 day Premium trial. Activate it with the button Rex sends you.

### How do I redeem a code?
Open the [Premium page](/premium), paste the code and press **Redeem**.

### Why can't I sign in or see my server?
Servers only show if you have *Manage Server* there and Rex is in them. Log out and back in if needed. See [Troubleshooting](/docs/troubleshooting).

### What if Rex is offline?
Check [Live stats](/live) for status and maintenance notices, then ask in the [Support Server](support:) if it persists.

### How do I report a bug or suggest a feature?
Use the [Support page](/support) or the [Support Server](support:) and explain the issue or idea clearly.

### How do I delete my data?
Open your **Profile** in the Dashboard and use the delete option, or contact us as described in the [Privacy Policy](/docs/privacy).

### Is it safe to share my bot token with support?
No. Never share your token, password or authentication codes with anyone, including people claiming to be Rex staff.

### Is Rex an official Discord product?
No. Rex is independent. Discord's own terms and policies apply separately.

## Glossary
| Term | Meaning |
|---|---|
| Administrator | A person with permission to manage a Discord server. |
| Moderator | A trusted staff member who enforces server rules. |
| Role | A group of permissions and labels given to members. |
| Permission | Authorisation to perform an action, such as managing messages. |
| Channel | A space in a server for messages, announcements or voice. |
| Slash command | A Discord command starting with `/`. |
| Embed | A formatted Discord message with headings and fields. |
| Interaction | Using a bot feature, such as running a slash command or pressing a button. |
| Dashboard | Rex's web interface for managing servers. |
| Tier | A level in Rex's plan structure: Free, Premium, Priority or Ultra. |
| Economy | A virtual-currency system inside a bot. It has no real-world value. |
| Bot token | A secret credential that lets software act as a Discord bot. Never share it. |
| OAuth2 | The Discord system that lets you sign in without giving your password. |
| API | A way for software systems to talk to each other. |
| Changelog | A record of updates and fixes. |
